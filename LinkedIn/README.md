## What This Folder Contains

### `LinkedIn_Caption.md`
Ready-to-paste LinkedIn post. Copy the text in the **Post Text** section directly into LinkedIn. Attach screenshots from `screenshots/` to the post.

### `Project_Summary.md`
Full technical and feature summary of Barn Brawl. Use for:
- Portfolio descriptions
- Project README supplementing
- Recruiters or collaborators wanting full detail
Includes verified feature list, tech stack, architecture, controls, and deployment info.

### `How_To_Play.md`
Complete player guide covering controls, boost mechanics, animal abilities, powerups, maps, and multiplayer tips. Useful for:
- Linking in the README
- Including in the LinkedIn post comments
- Adding to the game's in-browser help UI

### `Dreamina_Seedance_Trailer_Prompt.md`
Detailed per-clip prompts for Dreamina / CapCut Seedance to generate the gameplay trailer.
Instructions:
1. Open Dreamina (app.dreamina.com or CapCut)
2. Select Seedance 2.5 (or latest model)
3. For each clip, paste the corresponding prompt
4. Upload the relevant `trailer_references/` image(s) as visual reference
5. Generate clips one at a time
6. Assemble clips in CapCut or your video editor
7. Add title cards and the URL **in the editor** — do NOT rely on AI to render readable text

### `Trailer_Shot_List.md`
Shot-by-shot breakdown of the complete trailer sequence. Use while:
- Generating clips in Seedance (match each shot to its clip prompt)
- Editing the final video in CapCut or Premiere
- Planning music and SFX cue points
